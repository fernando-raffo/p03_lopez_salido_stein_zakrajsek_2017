# Manually-Created Data

This folder holds manually created data that cannot be easily replicated
programmatically.

No files are currently required here. The Greenwood-Hanson high-yield share
that previously lived in this folder (`greenwood_hanson_hys_historical.csv`) is
now downloaded directly from its published source — the HBS
`InvestorCreditSentiment.xlsx` workbook — by `src/pull_greenwood_hanson.py`
(issue #42), so it no longer needs to be committed.
